# Tableau-Desktop-Foundation-Exam-Prep
 
Flashcards for preparing for the **Salesforce Certified Tableau Desktop Foundations** exam (formerly Tableau Desktop Specialist).
 
## 👉 [Open the flashcards](https://samaardi.github.io/Tableau-Desktop-Foundation-Exam-Prep/)

## What's inside
 
229 cards covering every objective in the official exam guide, plus exam-style scenario questions like the ones in practice exams.
 
| Domain | Exam weight | Topics |
|---|---|---|
| 1. Connecting to & preparing data | 25% | Live connections vs extracts, file types (.twb, .twbx, .tds, .tdsx, .hyper), relationships, joins, unions, data blending, Data Interpreter, pivot, data types, aliases, geographic roles, default properties |
| 2. Exploring & analyzing data | 35% | Basic charts (bar, line, scatter, maps, dual and combined axis, highlight tables), groups, sets, hierarchies, filters and context filters, sorting, reference lines, trend lines, quick table calculations, bins, calculated fields, parameters, totals |
| 3. Sharing insights | 25% | Formatting, colour, shapes, animations, dashboards, layout containers, dashboard actions, device layouts, stories, exporting, publishing |
| 4. Understanding Tableau concepts | 15% | Dimensions vs measures, discrete vs continuous, aggregation, order of operations |
 
There is also a short deck on the exam format and test-taking strategy.
 
## How to study
 
1. Pick a domain, or study all cards. Click a domain name to study only that domain.
2. Read the question and answer it in your head.
3. Tap the card (or press **Space**) to flip it.
4. Be honest: click **I knew it** or **Review again**.
5. Later, turn on **Only "review again"** to practise the cards you missed.
Keyboard shortcuts: **Space** flip · **← →** move · **1** review again · **2** I knew it
 
Your progress is saved in your own browser only. Use the same browser and device each time, or your marks won't be there.
 
**Tip:** Domain 2 is the biggest part of the exam (about 14 of 40 questions), so spend the most time there.
 
## About the exam
 
- 40 scored multiple-choice and multiple-response questions
- 70 minutes
- Passing score: 48%
- Closed-book: Tableau Desktop is **not** available during the exam, so you need to know where menus and options are
Exam details can change. Check the official [exam page on Trailhead Academy](https://trailheadacademy.salesforce.com/certificate/exam-tableau-desktop-found---Analytics-101) before you book.
